💡 使用说明

  • 设置起始时间范围，服务器将在此时间范围内搜索
  • 添加匹配条件：天数区间 + 涨幅区间，可添加多组
  • 多组条件之间为 AND（同时满足）关系
  • 点击"开始匹配"后等待服务器返回结果
  • 支持将结果导出为JSON，也可从JSON导入

📖 条件示例

🔹 30天内涨幅 ≥ 100%

→ 天数最小=1, 天数最大=30, 涨幅最小=100, 涨幅最大=留空(不限)

🔹 5~10天内涨幅在50%~80%之间

→ 天数最小=5, 天数最大=10, 涨幅最小=50, 涨幅最大=80
